## 4. 缺口與限制

- **壯圍鄉中古透天樣本**：198 筆，分布跨度大（建坪中位 53.5 坪、屋齡中位 10.0 年）。若要對應本案（新建透天、3 層、無車位），建議進一步剖切：
    - 屋齡 ≤ 5 年（接近新成屋）
    - 主要用途=住家用、車位數=0
    - 總樓層 ≤ 3 層
- **預售建商**：實價登錄揭露**案名**但**不揭露建商**。如需建商名稱，需另查「營建署建照核發資料集」(data.gov.tw dataset 6303) 或 591 等商業站；商業站涉反爬機制，本批次未做。
- **人口/所得**：本壓縮包未含 data.gov.tw 鄉鎮人口、財政部綜所稅申報資料。表 3 待另行下載：
    - 內政部戶政司「鄉鎮市區人口指標」
    - 財政部財政資訊中心「綜所稅申報初步核定統計專冊」
- **異常極值**：表 1 每坪最高/最低差異極大（如宜蘭市每坪 0.4 ~ 561.7 萬），含部分共有人交易、夾雜土地交易、瑕疵戶等。中位數與 P25/P75 已可吸收，但若做散佈圖建議剔除 P1/P99。
